# Αποφάσεις

Σύντομο ημερολόγιο: τι αποφασίσαμε, πότε και γιατί.

## 2026-11-06

- **Το login είναι μέρος του site, ο backend ξεχωριστό repo.** Οι σελίδες ζουν στο `app/panhellenicexams` και μοιράζονται λογότυπο, γραμματοσειρές και χρώματα με το site. Ο auth backend είναι μόνος του στον φάκελο και στο repo `BACKEND`. Αντικαθιστά μια πρώτη εκδοχή όπου το login ήταν ξεχωριστή εφαρμογή Vite πίσω από rewrite· αυτή υπάρχει στο ιστορικό του repo `BACKEND`, στο commit `e6efece`.
- **Δικό του root layout.** Το login δεν έχει τον header και το footer του site, και η μετάβαση από το site σε αυτό είναι πλήρης φόρτωση σελίδας.
- **Είσοδος από την κάρτα «Γενικό Λύκειο».** Η κάρτα 06 στην αρχική οδηγεί στο `/panhellenicexams`.
- **Το session είναι httpOnly cookie που βάζει ο backend.** Κανένα token σε `localStorage` ή `sessionStorage`, ώστε να μην το διαβάζει JavaScript.
- **Αναγνωριστικό `app` αντί για URL επιστροφής.** Το frontend στέλνει μόνο `app: "eclass"` και ο backend αποφασίζει το URL από δική του λίστα, ώστε να μη γίνεται ανακατεύθυνση σε ξένη διεύθυνση. Αφού υπάρχει μόνο ένα app, το frontend δεν το διαβάζει από τη διεύθυνση.
- **Τον ρόλο τον εγκρίνει η γραμματεία.** Η εγγραφή ζητά ρόλο αλλά δεν τον δίνει, αλλιώς οποιοσδήποτε θα γραφόταν ως καθηγητής.
- **Συνέχεια χωρίς ξανά login.** Όποιος έχει ήδη session πηγαίνει κατευθείαν στο eClass, μέσω του `POST /api/auth/continue`.
- **Όλη η επικοινωνία με τον server περνά από το `app/panhellenicexams/_lib/api/`.** Αν αλλάξει ο backend, αλλάζει ένα σημείο.

## Ανοιχτά

- **Δικό μας auth σε Quarkus ή Keycloak.** Το Keycloak είναι έτοιμος server ταυτοποίησης χτισμένος σε Quarkus, με hashing, κλείδωμα, MFA και reset κωδικού έτοιμα. Το δικό μας Quarkus δίνει πλήρη έλεγχο αλλά όλα αυτά τα γράφουμε εμείς.
